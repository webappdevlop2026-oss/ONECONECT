How it works after backend connection

1. AdminAdd Service
Create service name, category, image and its own fields.
2. APISave Form Schema
Laravel stores the service and field definition in MySQL.
3. Vendor AppLoad Correct Form
Vendor taps the service and only that service's fields appear.
4. ListingSave Service Data
Submitted values are stored against that service only.
